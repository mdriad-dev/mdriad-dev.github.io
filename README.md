## Run locally

1. Clone this repository:

   ```bash
   git clone https://github.com/mdriad-dev/mdriad-dev.github.io.git
   cd mdriad-dev.github.io
   ```

2. Open `index.html` in a browser, or use the VS Code Live Server extension.

The live repository section requires an internet connection and may be limited by the unauthenticated GitHub API rate limit.

## Customize

- Edit profile content and featured projects in `index.html`.
- Adjust colors and layout variables at the top of `style.css`.
- Update animated headline phrases in `script.js`.
- Keep project links current as repositories change.

## Deployment

This repository is configured as the personal GitHub Pages site for `mdriad-dev`. Push changes to the `main` branch and GitHub Pages will publish the updated site at:

```text
https://mdriad-dev.github.io/
```
